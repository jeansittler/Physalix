# Physalix 1.0.0

Première version publique de Physalix.

Physalix est une application Windows destinée à l'exploitation et à la
visualisation de données expérimentales en physique.

## Installation

Télécharger `Physalix-Setup-1.0.0.exe` puis lancer l'installateur.

L'installation propose par défaut `C:\Program Files\Physalix`.
Le dossier peut être modifié pendant l'installation. Les droits administrateur
sont demandés. Un raccourci est créé dans le menu Démarrer ; le raccourci Bureau
est optionnel.

## Compatibilité

Windows 10 (1809 ou ultérieur) / Windows 11, 64 bits.

Python n'est pas nécessaire.

## Remarque Windows SmartScreen

L'installateur n'est pas encore signé numériquement. Windows SmartScreen peut
donc afficher un avertissement lors du premier lancement.

## Intégrité du téléchargement

Le fichier `Physalix-Setup-1.0.0.exe.sha256.txt` contient l'empreinte SHA-256
de l'installateur.
