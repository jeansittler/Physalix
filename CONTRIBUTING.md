# Contribuer à Physalix

Merci de contribuer à Physalix.

## Bugs et propositions

Avant d’ouvrir une issue, vérifiez qu’elle n’existe pas déjà. Décrivez le problème,
la version de Physalix et de Windows, le résultat attendu et les étapes minimales
pour reproduire. Ne publiez jamais de données personnelles, de secrets ou de
fichiers d’élèves. Pour une vulnérabilité, suivez plutôt [SECURITY.md](SECURITY.md).

## Pull requests

- Limitez chaque pull request à un changement cohérent et expliquez sa motivation.
- Ajoutez ou adaptez les tests lorsque le comportement change.
- Exécutez `python -m unittest discover -s tests -v` avant de proposer le changement.
- Ne modifiez pas la version, les URL de mise à jour ou le processus de publication
  sans discussion préalable.
- En proposant une contribution, vous acceptez qu’elle soit distribuée sous la
  licence GPL‑3.0-only du projet et vous confirmez avoir le droit de la soumettre.

Les échanges doivent rester respectueux, précis et centrés sur le projet.
